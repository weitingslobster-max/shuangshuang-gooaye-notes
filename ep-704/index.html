股癌 EP704 投資研究筆記

主軸：OpenAI run-rate 雜訊、Marvell Investor Day、AI data center 光互連、BMC / DCM 競合、TFLN / 3.2T 作夢行情，以及老水手式風控。

NotebookLM primarySocial Worker Daily secondarySupplementary triangulationConservative verification

核心結論

  1. 本集不是「AI 出事」，而是資訊口徑差異。 OpenAI 700B vs 500B annualized revenue 主要是 gross/net 與 Anthropic comparable methodology 的差異；主持人將短線閃崩視為雜訊。
  2. Marvell Investor Day 是本集最高價值研究主軸。 資料中心從單一晶片走向 rack / data-center-level interconnect，讓 SerDes、NPO、CPO、optics、custom XPU 成為長線追蹤重點。
  3. 遠期數字要折現。 FY2031 70–90B revenue target 與 56–59% gross margin 是官方長期模型，但時間長、假設多，不可直接變成短線買點。
  4. 光互連方向明確，但作夢行情很危險。 800G、1.6T 正在推進；3.2T、plasmonics、TFLN 更遠，主持人用 AOI 說明買對技術路線也可能多次腰斬。
  5. BMC / DCM 要看 total solution。 Marvell Data Center Management 不是單純搶 BMC 小市場；信驊、新唐的短線恐慌與長線 TAM 變化要分開查。
  6. 投資心法是控制部位，讓自己能忽略 noise。 SpaceX 8–10% 部位、All-weather、老水手 QA，都指向風險承受度與槓桿比方向感更重要。

追蹤計畫 / Event triggers

  • Marvell 下修 FY2028 / FY2031 road map 或 interconnect mix：降低 MRVL / optics thesis 信心。
  • Broadcom networking / switch / custom silicon guidance 顯著上修：提高 AI interconnect 供應鏈優先度。
  • 800G / 1.6T 出貨、ASP 或 CSP capex 放緩：檢查光通多頭是否過度折現。
  • Marvell DCM 被大型 OEM / CSP 採用並替代獨立 BMC：提高信驊 / 新唐風險權重。
  • 3.2T / TFLN 概念股大漲但無官方量產證據：標為作夢行情，不追高。
  • OpenAI / Anthropic revenue 口徑再引發急跌：先拆 gross/net / ARR / revenue recognition，再判斷 demand 是否變質。

方法限制

  • NotebookLM 未提供精確時間戳；Podcast 口語數字需回官方資料查證。
  • OpenAI / Anthropic / SpaceX 為未上市公司，收入與估值多為媒體或投資人文件轉述。
  • 本報告是研究筆記，不構成個人化投資建議；遠期技術與 FY2031 模型需高折現。
