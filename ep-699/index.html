EP699 投資研究筆記：AI Agent、CPU 二度催化、DSP 漲價與光通訊輪動

本集的投資主軸不是單一個股，而是三條研究線：指數創高後的市場情緒、Agentic AI 對 CPU demand 的重新定價、以及 高速光通訊中 DSP 的供需與技術路線。整體語氣偏向順勢觀察，但同時提醒市場已出現 FOMO 與誇張數字。

市場方向

創高附近轉空像摸頭；重點看盤面結構是否擴散。

AI Agent

Meta Muse 帶動 CPU 題材二度催化，但下載熱潮不等於長期 demand。

DSP / 光通訊

400G/800G/1.6T 規格升級支持 DSP 線索；15–20% 漲價仍待官方驗證。

核心結論

  1. 主持人不鼓勵在創高附近急著摸頭。 加權與 Nasdaq 接近 / 創新高時，部分投資人轉空被視為不順勢；但這不是無風險追高，而是提醒不要只因漲高就反向。
  2. CPU 是本集 AI 線索的核心，但要防止 FOMO 數字。 Agentic workflow 可能讓 CPU 在資料中心架構中更重要；不過 40:1 CPU/GPU 這類極端比例被主持人質疑，不應納入 base case。
  3. DSP 是可追蹤的產業線索。 主持人把 DSP 放在 400G、800G、1.6T 高速傳輸中理解，短期受缺貨與規格升級支持；長期則要觀察 CPO/LPO 對 DSP 價值鏈的改變。
  4. 宏碁案例適合轉化成「AI 落隊公司」研究框架。 這是主持人主觀評論，不應直接當成投資結論；更好的用法是建立落隊檢查表。
