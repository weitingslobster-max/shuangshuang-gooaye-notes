股癌 EP693：聯發科 ECB、NVLink Fusion / NVHBM 與 ASIC 競爭格局

來源層級：YouTube/NotebookLM primary report、Social Worker Daily validated secondary note、NotebookLM supplementary triangulation、外部公開資料查證。本文是研究筆記，不是投資建議。

核心結論

本集主軸不是單純「ASIC 取代 GPU」，而是 NVIDIA 透過 NVLink Fusion、NVHBM 與 MediaTek 合作，把 custom XPU 拉進其機櫃級 AI factory 生態。

Core takeaways / 核心結論

  • 本集投資主軸集中在 **NVIDIA 透過聯發科把 NVLink Fusion / NVHBM 推進客製化 XPU 生態系**，不是單純「誰取代誰」的零和敘事。
  • 聯發科 ECB 的投資意義偏向策略選擇權：NVIDIA 以可轉債形式加深與 MTK 的合作，使客製 XPU 即便不是 NVIDIA GPU，也更可能落在 NVIDIA 機櫃、互連、記憶體與軟體生態中。
  • Host stance 對 NVIDIA 與聯發科合作偏正向觀察，但對「NVIDIA、Google、MTK 三方結盟」的市場敘事保持保留：secondary note 也強調 Google 與 NVIDIA 是各自獨立參與。
  • NVHBM 是本集高價值追蹤點：來源稱頻寬較 HBM4E 增 30%、功耗少 15%，且把 controller 移到 HBM base die；但量產、供應商分工與毛利分配仍需查證。
  • Broadcom / Marvell / 世芯 / Google ICI / OCS 等議題應放在「ASIC 與 interconnect 競爭格局」內看：ASIC 出貨增加不必然代表 NVIDIA 衰退，因為 AI infrastructure TAM 仍可能擴大。
  • QA 中的風控框架比個別操作更可複用：美股單一部位上限較嚴、台股更重視流動性與跌停制度差異。

Topic map / 主題地圖

  • **AI infrastructure / rack-scale architecture**：NVLink Fusion、MGX rack、Vera CPU rack、STX / SPX / LPX、BlueField、Spectrum-X、NVLink-C2C。
  • **Semi-custom XPU**：hyperscaler / CSP / frontier model developer 可能自研 XPU，但仍可使用 NVIDIA 周邊架構。
  • **Memory architecture**：NVHBM 將 controller 移至 HBM base die，可能改變 HBM value capture。
  • **ASIC competition**：Broadcom、Marvell、世芯、MTK、Google ICI / OCS 共同構成 ASIC 與 interconnect 競爭圖。
  • **Market discipline**：震盪修復期避免過度追動能；依市場制度與流動性調整部位上限。

Draft investment hypotheses / 投資假說草稿

  1. **NVLink Fusion adoption hypothesis**：若更多 XPU 客戶採用 NVLink Fusion / MGX rack，NVIDIA 即使 GPU share 被部分稀釋，仍可能透過互連、rack、networking、software 和供應鏈捕獲價值。
  2. **MediaTek custom silicon option hypothesis**：聯發科若把 Google 練兵經驗擴展到其他 CSP / frontier model customers，長期收入組合可能從手機 SoC 擴大到 AI infrastructure custom silicon；但 tape-out、良率與客戶集中度是主要風險。
  3. **NVHBM value-chain hypothesis**：NVHBM 若量產並被 NVLink Fusion 客戶採用，可能讓 NVIDIA/設計方/先進封裝供應鏈取得更高控制權；但記憶體廠是否被壓縮毛利尚未證實。
  4. **Broadcom resilience hypothesis**：ASIC 市場擴大可能同時容納 Broadcom 與新進者，短線降評 / 傳聞造成股價波動不等於基本面受損。
  5. **Position-sizing hypothesis**：美股單一部位需考慮財報跳空，台股需更重視流動性與跌停制度；此原則比追逐單一消息更可持續。

Open verification queue / 待查清單

  1. MOPS / 聯發科海外可轉債公告：總額、票息、到期日、轉換價格、溢價、NVIDIA / Alphabet 各自認購金額。
  2. NVIDIA NVHBM 原始技術公告或 whitepaper：30% bandwidth、15% power、controller in base die、25% die-area benefit 的準確條件。
  3. MediaTek custom XPU pipeline：是否已有具名 CSP / hyperscaler / frontier model 客戶、tape-out 時程、量產貢獻區間。
  4. Broadcom / Marvell / Alchip / MediaTek 在 NVLink Fusion 或 UALink 等 interconnect 生態的實際商業模式與收入認列。
  5. Google ICI / OCS 與 NVIDIA NVLink 的互補或競爭關係：避免把同時投資 MTK 解讀成一致技術陣營。

Bottom line / 查證結論

官方資料足以支持「NVIDIA 與 MediaTek 深化合作、NVIDIA 投資 35 億美元可轉債、MediaTek 採用 NVLink Fusion 服務 custom XPU / rack-scale AI infrastructure」這條主線。較細的 ECB 條款、Alphabet 參與比例、NVHBM 效能數字與 HBM 供應鏈價值轉移，仍需標為待查或 vendor claim。最終研究結論應保守：把本集視為 AI infrastructure 生態綁定的高價值研究線索，而不是任何標的的買賣訊號。
