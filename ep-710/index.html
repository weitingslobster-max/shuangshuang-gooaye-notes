Core takeaways / 核心結論

  1. 風控優先於猜底。 主持人描述反彈追入後因買太多而減碼；「可能便宜」與「部位過大」可以同時成立。重點是承受能力，不是把每次修正都解讀成全面熊市。
  2. 需求強與股票不漲並不矛盾。 雲端公告支持Azure年增48%、Google Cloud年增103%、AWS年增39%。成長不會自動抵銷資本支出、現金流、估值與資金流風險；市場為何下跌仍是多因子問題。
  3. CPU需求與可交付供給要分開。 Intel官方支持「15年最強資料中心營收成長」；但PC疲弱、製造／封裝限制、AMD競爭與ARM架構分流，不能用單一需求訊號概括。
  4. 不要用逆勢上漲證明景氣輪動。 主持人提出基金unwind「減多、補空」解釋；尚缺資金流實證，也可能和基本面因素並存。
  5. NeoCloud風險是條件式劇本。 融資受阻→硬體／半成品釋出→短期拉貨受影響，尚非本次核實的倒閉潮。
  6. 來源糾錯比補滿故事重要。 不採用「全市場維持率已130%」的確定說法；Marvell／Lumentum僅查得洽談報導；3008／3108等代碼仍需原音定位。作者換股不能變成主持人推薦。
