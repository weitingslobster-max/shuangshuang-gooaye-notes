Core takeaways / 核心結論

  1. 本集最可研究主線是 AI 資料中心電力鏈。 800VDC 不是單純效率題材，而是由高功耗 rack 帶出的銅排、線纜、connector、power shelf、冷卻與空間瓶頸。
  2. 2026–2027 第一階段仍偏 Power Rack / PRC，受惠重點在 AC→800V PSU、800V→54V shelf、電容、連接器、BBU。 主持人語氣偏正向，但更像「下檔有基本面支撐」而非立即無腦上修估值。
  3. 第二、三階段更偏中長期夢想與基建升級。 Power Center、SiC/GaN、DC UPS、Busway、SSCB、BESS、DC Switchboard、重電與系統整合值得建研究清單，但時間點與訂單不能從白皮書直接推導。
  4. Cerebras / AMD disaggregated inference 是推論時代線索。 WSE / SRAM 低延遲 decode 與 AMD Helios / Instinct / EPYC 的分工值得追蹤；但 Cerebras 本身仍要分清「上市後 lockup / 解禁」與基本面。
  5. SpaceX / Cerebras 解禁討論是籌碼流動性模型，不是普遍定律。 主持人對流動性增加偏正向，因為價格發現更健康；但每家公司解禁條款、買方結構與基本面都需個別驗證。
  6. 筆記作者操作日記要隔離。 台達電、捷敏-KY 是 secondary note 作者個人操作紀錄，不是主持人明確推介；只能作為「市場可能聯想到的台股映射」待外部研究。

    Bottom line / 查證結論

    800VDC 作為 AI 資料中心高功耗下的電力架構升級，已獲 NVIDIA 官方資料支持，是本集最穩固的研究主線。Cerebras 已上市與 AMD/Cerebras inference 合作大方向也有外部支持；但「5% 滲透率」、「GaN 超缺」、「SpaceX 解禁批次」與任何台股個股對應仍屬待查或 secondary-only，不能直接轉成投資建議。
